## 2025-05-18 - A11y Attributes
**Learning:** Custom interactive elements like icon-only buttons, avatars, and mascots in SettingsMenu, EditProfileModal, and ProfileSetup needed aria-labels and appropriate roles (like menuitem and group) to be screen-reader friendly.
**Action:** Always add aria-labels to elements where visual text is missing or context is derived visually, and add focus-visible styles for keyboard navigation support.
